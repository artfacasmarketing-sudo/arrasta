# arrasta

Quando pedirem um carrossel nesta pasta, siga `.claude/skills/carrossel/SKILL.md`. É o mesmo ciclo do Claude Code:
`arrasta prompt` → você escreve o JSON em `resposta.txt` → `arrasta montar` → se sair `correcao.txt`, corrija e monte
de novo, no máximo 3 vezes → mostre a `previa.png`. Nunca chame `arrasta render` para texto seu.
